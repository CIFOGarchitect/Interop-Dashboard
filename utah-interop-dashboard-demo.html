How the real version gets its data

  • UCA official feed (authoritative, to be confirmed): system activity/status data from the system operator — the only source that covers the whole state.
  • Broadcastify Calls Client API (candidate): per-call metadata (system, talkgroup, time) for approved applications. Internal, restricted dashboards are a named legitimate use; a public statewide app would need an enterprise license instead. Verify a Utah node covers UCA before relying on it.
  • Broadcastify Live Audio Feed Catalog API: programmatic listing of the audio feeds above, so the real dashboard can link feeds by county automatically.
